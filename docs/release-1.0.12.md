# GenStudio 1.0.12 (13)

Create sound effects from a description, adjust duration and prompt guidance, and generate up to three results at once. Play and download each result, with automatic pausing when another sound starts. Simplified controls and improved landscape spacing keep the workflow easy to use.

Release target: Google Play Open Testing (beta), package com.oneimage.android.

Web verification: run `python scripts/verify-release-web.py` after deploying the sibling OneImage app. This compares the live bundle with the local production build and checks that the Sound Effects API requires authentication, without creating a task.
