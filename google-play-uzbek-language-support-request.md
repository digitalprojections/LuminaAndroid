## Subject

Request to add Uzbek (uz-UZ) as a supported Google Play store listing language

## Message

Hello Google Play Developer Support,

I am requesting support for Uzbek as a Google Play store listing localization language.

Our app, GenStudio AI Creator, package name com.oneimage.android, targets users in Uzbekistan and Uzbek-speaking communities worldwide. We tried to add an Uzbek store listing through the Android Publisher API using both uz-UZ and uz, but Google Play rejected both with this error:

> The requested language is not currently supported: uz-UZ.

We are able to publish nearby/regional language listings such as Turkish, Kazakh, Kyrgyz, and Russian, but we cannot publish an Uzbek listing even though Uzbek is the primary language for our target market in Uzbekistan.

We request that Google Play add Uzbek (uz-UZ) as a supported store listing language for:

- App title
- Short description
- Full description
- Localized store listing assets
- Android Publisher API listing updates
- Play Console "Manage translations" language selection

Business and user impact:

- We target users in Uzbekistan directly.
- We also target nearly 10 million Uzbek speakers overseas.
- Uzbek-speaking creators currently cannot see a native Uzbek Play Store listing for our app.
- This limits app discovery, trust, and accessibility for users who prefer Uzbek.
- We already have professionally prepared Uzbek listing copy ready to publish once the locale is supported.

Requested locale:

- Uzbek (Uzbekistan)
- BCP-47 code: uz-UZ
- Fallback code tested: uz

Please escalate this as a product/localization support request for Google Play Console and Android Publisher API language support.

Thank you.

- uz: rejected as unsupported
